# Legal and source notes

## What this package does not contain

It does not contain MTG Arena source code, extracted Arena client files, card art, mana-symbol artwork, audio, animations, card-frame graphics, or a bundled copy of the Comprehensive Rules.

## Rules source

The rules sync script downloads the official text directly from Wizards' public rules site for local development. Do not present your project as official, and do not redistribute Wizards material as though it belongs to you.

## Card data source

The card sync script uses Scryfall's documented bulk-data endpoint. Review Scryfall's API and image-use documentation before publishing or serving large amounts of data.

## MTGJSON option

MTGJSON publishes portable card databases under the MIT License. Keep its copyright and license notice when distributing a substantial copy of its software or data package.

## Existing engine options

- XMage: Java, MIT license, broad multiplayer and Commander support.
- Forge: Java, GPL-3.0. Reusing its code requires GPL compliance.
- phase-rs: Rust/WASM/React, dual MIT or Apache-2.0, newer project with a browser-oriented architecture.

Always verify the current license in the repository before copying or modifying code.
